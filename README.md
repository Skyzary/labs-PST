## 📖 Про репозиторій

Цей репозиторій містить лабораторні та практичні роботи, виконані в межах дисципліни «Стек технологій програмування».

Кожна робота розміщується в окремій директорії. Репозиторій оновлюється протягом семестру.

- 🚧 **У процесі** — робота виконується.
- ✅ **Виконано** — усі вимоги реалізовано, робота готова до перевірки.
- 🔄 **Потребує доопрацювання** — необхідні виправлення.
