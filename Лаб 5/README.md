# Лабораторна робота 5: ExpenseTracker

Консольна програма **ExpenseTracker** для обліку витрат, імпорту записів із JSON-файлів та перегляду статистики, реалізована на мові Ruby.

## 📋 Можливості

- Додавання витрати з автоматичною генерацією унікального `id`.
- Перегляд усіх витрат у вигляді таблиці з відображенням суми у гривнях (`12550` → `125.50 грн`).
- Фільтрація за категорією (`food`, `transport`, `study`, `entertainment`, `other`) та періодом дат (`YYYY-MM-DD`).
- Видалення витрати за `id` із підтвердженням.
- Статистика витрат: загальна кількість, загальна сума, середня, найбільша/найменша витрата та розподіл за категоріями.
- Імпорт витрат із JSON-файла з валідацією записів і захистом від конфліктів `id`.
- Збереження даних у локальному JSON-файлі (`expenses.json`) з перевіркою цілісності під час запуску та відкатом змін у пам’яті в разі помилки запису.

## 📁 Структура

```text
Лаб 5/
├── validator.rb  # Валідація полів запису витрати
├── expense.rb    # Модель Expense і форматування суми
├── storage.rb    # Завантаження та збереження JSON-файла даних
├── tracker.rb    # Бізнес-логіка (додавання, видалення, фільтрація, статистика, імпорт)
├── cli.rb        # Консольне меню та взаємодія з користувачем
├── main.rb       # Точка входу
└── README.md     # Документація роботи
```

## 🚀 Запуск

```bash
cd "Лаб 5"
ruby main.rb
```

Можна також передати шлях до файла даних як аргумент:

```bash
ruby main.rb path/to/expenses.json
```
