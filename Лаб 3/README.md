# Лабораторна робота 3: Гра «Морський бій»

Консольна гра **«Морський бій»** (Battleship), реалізована на мові Ruby за принципами об'єктно-орієнтованого програмування. У грі користувач змагається проти комп'ютерного супротивника на полях розміром 10×10.

---

## 📋 Опис та функціонал

- **Ігрове поле 10×10**: відображає воду (`~`), власні кораблі (`■`), промахи (`•`), влучання (`✕`) та потоплені судна (`🕱`).
- **Склад флоту (10 кораблів)**:
  - 1 чотирипалубний (4 клітинки)
  - 2 трипалубні (3 клітинки)
  - 3 двопалубні (2 клітинки)
  - 4 однопалубні (1 клітинка)
- **Правила розміщення**: кораблі генеруються автоматично, не перетинаються та не торкаються один одного (зокрема по діагоналі, дотримуючись буферної зони в 1 клітинку).
- **Розумний AI**:
  - Не стріляє двічі в одну й ту ж клітинку.
  - При влучанні переходить у режим тактичного добивання пошкодженого корабля вздовж лінії поранень.
  - При повному знищенні судна автоматично маркує сусідні клітинки як промахи.
- **Обробка помилок**:
  - Створено власні класи винятків (`InvalidCoordinateError`, `CellAlreadyHitError`).
  - Коректна обробка неправильного введення без падіння програми.
- **Збереження статистики**: ведеться підрахунок зіграних партій, перемог, поразок та відсотка перемог у файлі `stats.json`.
- **Зручне меню**: перегляд правил, запуск гри, перегляд статистики та вихід.

---

## 📁 Структура проєкту

```text
Лаб 3/
├── errors.rb       # Власні класи винятків (Battleship::GameError тощо)
├── ship.rb         # Клас Ship (модель корабля, координати, пошкодження)
├── board.rb        # Клас Board (ігрове поле 10x10, розміщення, відображення, постріли)
├── player.rb       # Класи Player, HumanPlayer, AIPlayer (алгоритм вибору цілей)
├── statistics.rb   # Клас Statistics (збереження та виведення статистики у JSON)
├── game.rb         # Клас Game (ігровий цикл, черговість ходів, перевірка завершення)
├── menu.rb         # Клас Menu (текстове головне меню гри)
├── main.rb         # Головна точка входу
└── README.md       # Документація роботи
```

---

## 🚀 Запуск гри

Перейдіть у папку з лабораторною роботою та запустіть скрипт `main.rb`:

```bash
cd "labs/Лаб 3"
ruby main.rb
```

Або з кореня репозиторію:

```bash
ruby "labs/Лаб 3/main.rb"
```

### Формат координат для пострілу

Вводити координати можна у довільному регістрі (з пробілом або без):
- `A1` або `a1`
- `B 5` або `b5`
- `J10` або `j10`
- Введення `q` або `exit` під час гри дозволяє достроково здатися і повернутися в меню.
