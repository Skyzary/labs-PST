# Лабораторна робота 4: Гра «Судоку»

Консольна гра **«Судоку»**, реалізована на мові Ruby без використання сторонніх бібліотек.

## 📋 Реалізований функціонал

- **Поле 4×4 (блоки 2×2)** та додатковий режим **9×9 (блоки 3×3)**.
- **Три рівні складності** (*Легкий*, *Середній*, *Складний*) із заздалегідь заданими полями та коректними розв'язками.
- **Відображення поля** в консолі з нумерацією рядків і стовпців, межами блоків та символом `.` для порожніх клітинок.
- **Перевірка правил** після кожного ходу (унікальність у рядку, стовпці та блоці) із детальним повідомленням про помилку.
- **Захист початкових клітинок** від зміни.
- **Обробка некоректного введення** (формат, вихід за межі поля, нечислові значення).
- **Перевірка перемоги** після кожного ходу.
- **Додаткові можливості**:
  - скасування останнього ходу (`u` / `undo`);
  - підказки (`h` / `hint`);
  - статистика ходів, помилок, підказок, скасувань та часу гри;
  - дострокове завершення гри (`q` / `quit`).

## 📁 Структура

```text
Лаб 4/
├── puzzles.rb   # Початкові поля та розв'язки (4×4 та 9×9)
├── board.rb     # Клас Sudoku::Board (двовимірний масив, перевірка правил, рендер)
├── game.rb      # Клас Sudoku::Game (ігровий цикл, команди, історія, статистика)
├── main.rb      # Клас Sudoku::Menu та точка входу
└── README.md    # Документація роботи
```

## 🚀 Запуск

```bash
cd "Лаб 4"

```
